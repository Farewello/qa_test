# Knowledge Index

这是 Project Knowledge 的唯一一级入口。默认只读取本文件，不递归扫描整个 `knowledge/`。

## 已登记知识

当前没有可登记的稳定项目知识。

只有当资料能够证明某项认知是项目特定、稳定且可复用时，才在 `knowledge/` 下创建对应文件并在此登记。不要为了目录完整创建空模块。

## 路由规则

1. 从当前 Change 中识别实体、动作、状态、角色和显式模块。
2. 只读取本索引命中的知识文件。
3. 只有明确依赖被触发时才扩展到其他模块。
4. Knowledge 不足或冲突时，才回溯当前 Change 引用的技术文档或必要历史记录。
