# Requirement Analysis: 文件导出

## 1. Requirement Goal

提供“文件导出”能力。当前 Evidence 只有功能名称，无法确认业务入口、导出对象或验收标准。

## 2. Confirmed Existing Behavior

没有 Evidence 描述现有行为，不能确认系统当前是否完全不支持导出、已有局部导出，或本次仅修改既有导出能力。

## 3. Confirmed New Behavior

唯一可确认的新意图是计划提供或调整某种文件导出能力。导出范围、格式、权限、执行方式和失败行为均未确认。

## 4. Affected Modules

- 显式模块：未提供。
- 候选模块：业务列表/查询、权限、文件生成、任务调度、存储与下载；这些只是路由候选，不是已确认依赖。

## 5. Change Impact

| Dimension | Confirmed conclusion | Gap |
|---|---|---|
| Business rules | 需要支持文件导出 | 导出对象、字段、范围不明确 |
| State | 无已确认状态变化 | 是否存在导出任务状态未知 |
| Permission | 无已确认权限规则 | 角色、租户隔离、脱敏未知 |
| Data | 无已确认数据规则 | 筛选、排序、快照、时区、精度未知 |
| Interface | 无已确认接口 | 同步下载或异步任务未知 |
| Dependency | 无已确认下游依赖 | 存储、通知、任务系统未知 |

## 6. Candidate QA Risks

以下是应验证的通用候选风险，不代表本系统已存在这些行为：

- 页面筛选条件与导出数据不一致；
- 越权导出、跨租户数据泄漏或敏感字段未脱敏；
- 大数据量导致超时、内存压力、重复任务或下载失败；
- CSV/Excel 编码、公式注入、换行和特殊字符处理错误；
- 导出过程中源数据变化导致快照不一致；
- 文件过期后仍可访问，或下载链接可被其他用户复用。

## 7. Failure, Boundary and Compatibility

- Failure：生成失败、存储失败、下载失败、任务取消和重试策略待确认。
- Boundary：零条、单条、大数据量、最大字段长度和特殊字符待确认。
- Concurrency：重复点击、并发导出、导出期间数据变更待确认。
- Async：是否异步、状态展示和通知机制待确认。
- Security：权限、脱敏、租户隔离、链接有效期和 CSV 公式注入待确认。
- Compatibility：浏览器、操作系统、Excel/CSV 打开兼容性范围待确认。

## 8. Regression Scope

当前只能确定应回归导出入口所在页面及其查询条件；由于模块和实现均未知，无法给出可靠的具体回归模块清单。

## 9. Unknowns

- UNK-001: 发起页面和业务模块。
- UNK-002: 导出范围以及筛选、排序、分页规则。
- UNK-003: 文件格式、编码、字段、文件名、时间和数字格式。
- UNK-004: 角色权限、租户隔离和敏感信息脱敏。
- UNK-005: 同步/异步机制、数据量上限、超时和重试。
- UNK-006: 空数据、失败、取消、过期和重复下载行为。
- UNK-007: 数据快照和并发变更语义。

## 10. Assumptions

无。当前分析不采用业务假设替代缺失规格。

## 11. Questions

优先确认 UNK-001～UNK-005；这些答案决定主体用例是否可执行。UNK-006～UNK-007 决定异常、可靠性和一致性测试范围。

## 12. Test Focus

- TF-001（P0）：明确业务入口后验证用户能够发起文件导出；受 UNK-001、UNK-003 阻塞。
- TF-002（P0）：验证导出数据与选择范围、筛选、排序及分页规则一致；受 UNK-002 阻塞。
- TF-003（P0）：验证权限、租户隔离和敏感字段处理；受 UNK-004 阻塞。
- TF-004（P1）：验证空数据、边界数据量和大数据量行为；受 UNK-005、UNK-006 阻塞。
- TF-005（P1）：验证特殊字符、编码、时间、数字和潜在公式注入；受 UNK-003 阻塞。
- TF-006（P1）：验证重复操作、并发导出和数据快照一致性；受 UNK-005、UNK-007 阻塞。
- TF-007（P1）：验证生成、存储、下载失败以及超时、取消和重试；受 UNK-005、UNK-006 阻塞。
- TF-008（P2）：验证文件下载与打开的客户端兼容性；受 UNK-003 阻塞。

## 13. Knowledge Candidates

无可写入候选。除“计划存在文件导出能力”外没有稳定规则，而该表述过于宽泛，不能为未来任务提供可靠路由或测试决策。
